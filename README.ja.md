# Moat

**数値を報告する前に、外堀を埋める。**

出荷ではなく**研究**をする AI コーディングエージェントのためのスキル集です。
成果物が「測定についての主張」になる仕事に効きます。やることは一つで、
**棄却できない数値をあなたに手渡させない**こと。

研究のコストの大部分は、結果を計算することではありません。結果を**棄却可能**に
することです —— それを露呈させたはずの対照、値を既に知っていたセル、誰かが
見る前に書いておいた閾値。この作業を要求する人は、どこにもいません。
答えへの最短経路を最適化するエージェントは全部飛ばしますし、**飛ばしても
答えの見た目は変わりません。**

これは意図的に高コストです。「動く最小のものを作る」エージェントが欲しいなら
最小主義のスキルを使ってください（良いものがいくつもあります。本スキルは
その競合ではありません）。こちらを使うのは、**誤った数値のコストが、無駄になった
午後より高い**場合です。

## 何をするか

`moat` は測定の仕事に常時かかる指針です。10の規則で、**どれも撤回する羽目に
なった結果の代価として得られたもの**。適用される順に並んでいます。

1. **見る前に閾値を登録する** —— そして各結果が何を意味するかまで書く
2. **パイプラインの外にセルを1つ固定する。**再現しなければ他は一切読まない
3. **陰性対照は、起こりうる誤りを1つずつ名指しで実装する。**期待値を先に書く
4. **器具確認と対照は主値より先に印字する。**落ちた腕は読まない
5. **自明解は腕である** —— 何もしない / 全部やる / 既存の道具だけ
6. **数値はその量・設定・閾値を連れて動く。判定語はその閾値を連れて動く**
7. **学習した数値の隣に、学習なしの度数表を置く**
8. **母集団を混ぜない。**課題の違うプールを平均しない、ほぼ空の単位を平均に入れない
9. **撤回は、最新の1か所への追記ではなく、全ての複製先への1巡**
10. **データが何を写しているかは、その領域の専門家が決める**

加えてコマンドが4本:

| コマンド | 何をするか |
|---|---|
| `/moat-register` | 事前登録ファイルを書く —— 腕、主値、層、器具確認、陰性対照、合格基準、そして**この実験で決められないこと**。落ちようのない基準は却下する |
| `/moat-controls` | 陰性対照を誤りの型ごとに提案し、「対照が生まれつき無意味になる3つの道」に当てて点検する |
| `/moat-audit` | 出来上がった結果・報告・下書きを読んで、信用できない箇所を挙げる —— 裸の数値、閾値なしの判定語、見出しに出ている未読の腕、混ぜられた母集団、動いた閾値、欠けている自明解、外部に固定されていない器具 |
| `/moat-retract` | 撤回を全ての保管先に1巡で伝播させる —— その数値が**実際には何の量だったか**と、それに乗っていたものまで含めて |

`skills/moat/references/incidents.md` に、これらの規則の代価となった事故の記録
（抽象化済み）があります。規則が細かすぎると感じたときに読んでください。

## 導入

Claude Code:

```
/plugin marketplace add kuromook/moat
/plugin install moat@moat
```

他のスキル対応エージェント: `plugins/moat/skills/moat/SKILL.md` をプロジェクトに
コピーするか、スキルとして読ませてください。

**スキル本体は英語です** —— エージェントが読むものなので、短く済む言語に寄せて
あります。この README だけが日英両方です。

## これは何ではないか

- **方法論の講義ではない。**各規則は操作的です。書くべき成果物か、足すべき腕を
  名指しします
- **実装の仕事向けではない。**測定のコードと、報告される数値だけが対象です。
  判定は「結果が逆に出たら、自分の言うことが変わるか」です。変わらないなら
  このスキルの出番ではありません
- **統計ライブラリではない。**数値は計算しません。**数値が意味を持つために
  何が先に存在していなければならないか**を決めます

## 出どころ

ある長期の画像研究プロジェクトが、自分の失敗の台帳を付け続けていました。
その記録で印象的なのは**書かれていないこと**です —— コードを書きすぎて失った
ものはほとんど無く、失われたもののほとんどは、**量を連れずに動いた数値**、
**落ちようのない対照**、**自分自身を測っていた器具**でした。
ここにある規則はその台帳を一般化したもので、プロジェクト固有の内容は
取り除いてあります。

捕まえられなかった事故**を教えてもらえると助かります。
